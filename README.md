# Task 2 - Tic-Tac-Toe AI

Play as X against a computer that uses minimax to choose optimal moves. With perfect play, the game ends in a draw rather than an AI loss.

## Run

```bash
python3 tictactoe.py
```

Enter a square number from 1 to 9 as shown on the board, or `q` to quit. The search explores legal moves, scores wins/draws/losses, and prefers faster wins and slower losses.
